# Granite Texture Assets

This folder is reserved for future real granite texture images used in the catalog.

Recommended structure:

- `grey/`
- `red/`
- `black/`
- `green/`
- `white/`
- `brown/`
- `blue/`
- `violet/`

Recommended file naming:

- `swatch-01.jpg`
- `swatch-02.jpg`
- `hero-closeup.jpg`
- `full-slab.jpg`

Suggested usage:

- `swatch-*` for small palette tiles
- `hero-closeup.*` for the large featured texture preview
- `full-slab.*` for future detailed catalog sections

Current UI still uses CSS-generated placeholder textures. Real image integration can be wired later to these folders.
