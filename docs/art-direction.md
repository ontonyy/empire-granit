# N3 Art Direction — Workshop Reportage

## Voice
Documentary, not commercial. The workshop is the protagonist; the studio names a craft, not a product line. No marketing superlatives, no decorative flourishes, no funerary symbolism (no candles, crying mourners, cemetery wide-shots).

## Palette
Tokens live in `src/styles/tokens.css`. Cool stone neutrals + a single warm accent.

| Token | Hex | Role |
|---|---|---|
| `--paper-warm-white` | #f5f1ec | Page surface |
| `--paper-ivory` | #ede7dd | Section ground |
| `--ink-near-black` | #1b1a17 | Primary type |
| `--ink-ash` | #4a4944 | Body type |
| `--accent-wood` | #7a5b3a | Single warm accent (links, eyebrows, dividers) |
| `--rule-bone` | rgba(27,26,23,0.18) | Hairline rules |

Legacy palette (cream/granite-grey/cinzel-gold) dropped in Wave 3.

## Typography
Inter for everything; EB Garamond italic for accents only. No display serif (Cinzel + Cormorant retired in Wave 3).

- `--font-base: 'Inter', system-ui, sans-serif`
- `--font-italic-accent: 'EB Garamond', Georgia, serif` — used only on `.cinzel-font` headings and pull-quotes
- Display sizes use `clamp()` for fluid type; weight 500 max
- `font-display: swap` via Google Fonts URL
- Async font CSS load via `media="print" onload` pattern in `index.html`
- LCP-critical text (contact phone number) falls back to system stack first to avoid web-font wait

## Photography direction

### Choose
- Hands working stone, edges, tools, light on raw granite
- Workshop interior wide-shots, dust motes, scale references
- Material close-ups (engraving, polish, framing)
- Installation sites without grieving subjects

### Reject
- Mourners, candles, crying faces, funeral processions
- Wide cemetery rows with crosses (use neutral installation context only)
- Saturated color, golden-hour glow, religious iconography
- Stock-template "memorial" composites

### Treatment
- Desaturated / cool palette (or post-correct)
- Landscape hero, portrait/square supporting
- AVIF primary, WebP fallback, JPG last-resort
- Two density variants (1x / 2x) generated by the build, served via `<picture>` + `srcset`

## Motion
- `reveal-on-scroll` for entry; opacity + 12px lift; 600ms ease-out
- No parallax, no auto-rotating carousels
- Hover: 1px border movement only on interactive cards
- Reduced-motion: all transitions collapse to opacity <= 200ms

## Layout grammar
- Asymmetric editorial grids (e.g. Works essay 7-cell grid with type-only cells `--b`, `--g`)
- Long-form measure ~62ch
- Gutter via `--space-*` scale (4 / 8 / 12 / 16 / 24 / 32 / 48 / 80)

## Do / Don't (one-liners)
- DO use one accent color; DON'T tint photography
- DO break grids on purpose; DON'T center everything
- DO leave breathing room; DON'T fill every cell
- DO label material + place; DON'T add prose captions
